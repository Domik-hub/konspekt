# Конспект

Личное учебное приложение на русском языке. Материалы обрабатываются на устройстве пользователя.

## Возможности

- PDF с текстовым слоем, DOCX, TXT и Markdown; до 5 файлов по 10 МБ.
- Вставка текста до 120 000 символов.
- Вопросы по определениям и фактам: выбор ответа, восстановление пропуска и объяснение определения.
- Настройка количества, формата и уровня вопросов.
- Самопроверка, карточки, ответы с исходными фрагментами и экспорт TXT.
- Последние 20 наборов и 100 результатов хранятся в localStorage браузера.

Вопросы составляет локальный алгоритм, без внешнего ИИ и ключей. Он не добавляет факты вне лекции. Если текст не даёт достаточно уникальных вопросов или подходящих альтернатив, набор получается короче либо вопрос становится открытым. Открытые ответы оценивает сам пользователь. PDF-сканы требуют предварительного OCR; OCR и аудиолекции не поддерживаются.

## Разработка

Требуется Node.js 22.18+ (рекомендуется 24).

```sh
npm install
npm run dev
node --experimental-strip-types scripts/check-questions.mjs
npx tsc --noEmit
npm run build
```

Стек: React, Vinext, Vite, pdf.js и Mammoth. Worker и ассеты публикуются через Sites. `public/pdf.worker.min.mjs` соответствует pdfjs-dist 4.10.38; при обновлении библиотеки нужно обновить файл Worker.

Пользовательские лекции не отправляются на сервер. Сохранённые наборы относятся только к этому браузеру и не синхронизируются между устройствами. Очистка данных браузера удалит историю.

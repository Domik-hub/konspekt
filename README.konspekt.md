# Конспект

Личное учебное приложение: загрузи лекцию, создай вопросы и проверь понимание.

## Возможности

- PDF с текстовым слоем, DOCX, TXT и Markdown; до 5 файлов по 10 МБ и 120 000 символов суммарно.
- Режим «Нейросеть»: вопросы по смыслу, связям и применению материала, без случайных пропусков слов.
- Язык вопросов и разбора: русский, казахский или английский независимо от языка лекции. Интерфейс остаётся русским, цитаты — на языке оригинала. Выбор сохраняется в браузере и в каждом наборе.
- Открытые ответы проверяются по смыслу: 1 балл за верный, 0,5 за частичный, 0 за неверный. Обратная связь объясняет, что верно и чего не хватает. Синонимы, перефразирование и правильный ответ на другом языке допустимы.
- При ошибке проверки ответ остаётся на экране: можно повторить запрос или продолжить без оценки. Неоценённые вопросы не входят в знаменатель результата.
- Вопросы с вариантами проверяются сравнением с правильным вариантом без дополнительного запроса к API.
- Порядок вариантов формирует приложение: верные ответы распределяются между позициями, отвлекающие варианты перемешиваются. Старые наборы обновляются при загрузке; при новой тренировке порядок меняется, но во время ответа остаётся стабильным. Проверка использует текст правильного ответа, а не номер варианта.
- Явный локальный режим без внешней нейросети: базовые задания по словам и определениям, открытые ответы оценивает пользователь. Он не переводит исходную лекцию. Пример «Как работает память» тоже локальный.
- Карточки, цитаты из лекции, экспорт TXT, последние 20 наборов и 100 тренировок в localStorage. Старые наборы и результаты совместимы.

PDF-сканы требуют предварительного OCR; аудио и OCR не поддерживаются. Сохранённые наборы не синхронизируются между устройствами. Для содержательных вопросов по старому локальному набору нужно снова загрузить исходную лекцию и выбрать «Нейросеть».

## Локальная версия с подпиской ChatGPT

Запуск: `npm run local:build`, затем `npm run local:start` (Node.js 24). Открыть `http://127.0.0.1:4317` и нажать **Continue with ChatGPT**. `node local/launcher.mjs` запускает сервер в фоне и открывает браузер; `--stop` завершает сервер, `--no-open` запускает без открытия браузера.

Используется официальный поток [ChatGPT plan usage для локальных приложений](https://developers.openai.com/siwc/token-sharing-open-source): динамический клиент, постоянный ID установки, PKCE S256, одноразовые state/nonce, проверка подписи ID token через JWKS, issuer/audience/expiry/subject, отдельные регистрации аккаунтов и сериализованное обновление токенов. Доступ к нейросети возможен только с выданным `chatgpt.tokens.use.direct`. Модели загружаются из каталога выбранного аккаунта. Запросы отправляются на публичный Responses API с `store:false`, `stream:true`; только событие `response.completed` считается успешным результатом.

OAuth-токены сохраняются в игнорируемой `.local-data/`: на Windows — DPAPI CurrentUser, на Unix — файл с правами 0600 в папке 0700. Браузер получает только сведения об аккаунте и моделях. Токены не возвращаются клиенту, не записываются в логи и не передаются через URL. Повторный вход переиспользует client ID и ID установки. Выход останавливает запросы, пытается отозвать refresh token и очищает локальные токены, сохраняя регистрацию.

Сервер слушает только `127.0.0.1`, проверяет Host, Origin и CSRF для POST, ограничивает размер и частоту запросов и не разрешает CORS. Сессия браузера — HttpOnly/SameSite=Lax. Статические файлы отделены от исходников и хранилища. Открытые порты, облачный хостинг и копирование credential-файлов этой версии не поддерживаются.

Генерация вопросов через подписку использует `reasoning.effort:low` для сокращения задержки; смысловая проверка ответа сохраняет стандартное усилие выбранной модели. Набор показывается после полного завершения и проверки результата. Длительность зависит от модели, объёма лекции, числа вопросов и текущей нагрузки сервиса.

В локальной версии `OPENAI_API_KEY` не используется, даже если задан в окружении. Доступ и лимиты определяются аккаунтом и согласием OpenAI; реальные генерация и проверка требуют завершённого входа. Ошибка лимита не вызывает повтор или другое списание. В интерфейсе есть [управление лимитами ChatGPT](https://chatgpt.com/settings/usage). Авторизация по подписке не подключает старый опубликованный Sites-сайт.

Проверки: `npm run local:test` — фикстуры OAuth/JWT, изоляция аккаунтов, ротация/отзыв токенов, Windows-шифрование, HTTP-защита, корректность потоковых ответов, вопросы и оценка на трёх языках. Они не расходуют подписку. На Windows тесты хранилища и HTTP требуют обычного пользовательского окружения с доступом к DPAPI и loopback. `node node_modules/typescript/bin/tsc --noEmit` проверяет типы.

## Другие ИИ в локальном сайте

В верхней части сайта можно выбрать ChatGPT, Claude, Gemini, Grok, Qwen или DeepSeek. Выбор общий для создания вопросов и проверки открытых ответов, сохраняется после перезапуска. Чужой сервис никогда не подменяется ChatGPT при ошибке. Опубликованный сайт этим изменением не обновляется.

Claude Code, Gemini CLI, Grok Build и Qwen Code запускаются как официальные неизменённые клиенты в фоне, с отдельными профилями внутри `.local-data/providers/`. Для DeepSeek используется минимальный процесс из официальных пакетов Harness: аккаунт, локальный OAuth callback и вызов модели, без агента и инструментов. Кнопка входа запускает собственный браузерный вход клиента. Конспект не читает и не копирует их OAuth-токены. У каждого сервиса собственные условия доступа и лимиты; ChatGPT Pro не даёт доступ к другим подпискам.

Qwen использует `qwen-subscription` и требует **Qwen Plus или Pro**; прежний бесплатный Qwen OAuth не используется. Вход проходит через официальный `qwen serve`, защищённый случайным локальным токеном, модель выбирается из доступных подписке. DeepSeek использует **DeepSeek Account** в Harness: запросы расходуют его баланс/бонусы, а не бесплатный лимит потребительского чата. Пополнение баланса приложение не выполняет. Ссылки входа показываются только для официальных доменов. Ни одно подключение не требует ввода API-ключа.

Версии клиентов зафиксированы в `local/provider-packages.json`. Они устанавливаются через npm в игнорируемую `.local-tools/`: скопируйте этот файл в `.local-tools/package.json` и выполните `npm install --prefix .local-tools`. Node.js 24. `node scripts/probe-clients.mjs` проверяет запуск клиентов и протокол без входа и запросов к моделям. Для фактической проверки генерации нужен вход в выбранный сервис.

Запросы передаются через stdin / ACP, без shell и без текста лекции в аргументах процесса. Инструменты, хуки, расширения и сторонние MCP отключены для учебных запросов. В процессы не наследуются API-ключи и альтернативные API-шлюзы. Ответы всех ИИ проходят общие проверки схемы, цитат, вариантов, языка запроса и оценки. Состояние подключений не содержит секретов. Нативные клиенты самостоятельно хранят свои учётные данные; отключение удаляет только изолированный профиль этого сайта.

Официальные способы: [Claude Code и подписка](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan), [вход Gemini CLI](https://geminicli.com/docs/get-started/authentication/), [Grok Build](https://docs.x.ai/build/overview), [вход Qwen с подпиской](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/auth/), [DeepSeek Harness Account](https://deepseek-harness.github.io/deepseek-harness/en/reference/subsystems/credentials).

## Подключение ИИ на опубликованном Sites-сайте

Без серверного секрета `OPENAI_API_KEY` режим ИИ показывает, что подключение не завершено. Локальный режим доступен. Значение ключа никогда не вводится в интерфейсе, не возвращается браузеру и не включается в сборку.

На Sites ключ настраивается как секретная переменная окружения `OPENAI_API_KEY`. После изменения переменных требуется публикация версии. Сохраняйте приватный доступ сайта: API использует доверенную аутентификацию Sites.

Для локальной разработки Cloudflare Vite использует игнорируемый файл `.dev.vars` в корне проекта. Безопасно сохранённый `.env.local` можно использовать как источник ключа при настройке среды; сам по себе он не настраивает секрет на опубликованном сайте. Не копируйте секрет в отслеживаемые файлы. Не используйте префикс `NEXT_PUBLIC_`.

`OPENAI_MODEL` необязателен, по умолчанию `gpt-5.4-mini`. Сервер обращается к Responses API со строгой JSON-схемой и `store: false`. Использование API может расходовать средства аккаунта. Проверка статуса подтверждает только наличие настройки, а не баланс или действительность ключа.

## Данные и ограничения

Файлы разбираются в браузере. В режиме ИИ извлечённый текст отправляется выбранному провайдеру для вопросов; для проверки — вопрос, критерии, цитата и ответ ученика. Название получателя показано рядом с загрузкой. В режиме «Локально» эти данные не передаются внешнему ИИ. Наборы и история сохраняются на устройстве. Исходная лекция целиком не хранится в библиотеке.

Сервер проверяет размер запросов, схему результатов, соответствие формату, наличие правильного варианта и вхождение цитаты в исходный текст. Лекция и ответ ученика передаются как недоверенные данные отдельно от инструкций. Эти проверки не гарантируют смысловую безошибочность модели: пользователю доступен источник для сверки.

Проверка происхождения запроса и аутентификация защищают API. Ограничение частоты в памяти одного Worker снижает повторные запросы, но не является глобальным лимитом расходов. HTTP-ошибки, истёкший ключ, квота и неопределённая оценка отображаются без сырых ответов провайдера. Автоматических повторов и скрытой подмены нейросети локальным алгоритмом нет.

## Разработка и проверки

Node.js 24.9+:

```sh
npm install
npm run dev
node --experimental-strip-types scripts/check-questions.mjs
node --experimental-strip-types --test scripts/check-ai.mjs
npx tsc --noEmit
npm run build
```

Тесты ИИ используют подставные ответы провайдера и не выполняют сетевых или платных запросов. Они проверяют контракты, языки, источники, оценки, ограничения и ошибки. Для проверки реального качества вопросов и перефразированных ответов требуется отдельная проверка после настройки ключа.

Стек: React, Vinext, Vite, pdf.js, Mammoth, Zod. Worker и ассеты публикуются через Sites. `public/pdf.worker.min.mjs` соответствует pdfjs-dist 4.10.38.

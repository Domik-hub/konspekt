# Конспект

Сайт для подготовки по лекциям: загрузи материал, получи вопросы и проверь свои ответы.

## Возможности

- PDF с текстом, DOCX, TXT и Markdown или вставка текста.
- Вопросы по смыслу лекции с вариантами ответа и открытым ответом.
- Проверка ответа своими словами, объяснение оценки и цитата из источника.
- Русский, казахский и английский для вопросов и разбора; интерфейс на русском.
- Тренировки, карточки, история и экспорт. Правильные варианты перемешиваются.
- Выбор ChatGPT, Claude, Gemini, Grok, Qwen или DeepSeek; каждый пользователь подключает собственный аккаунт.
- Отдельный локальный режим без внешней нейросети.

## Быстрый запуск

Нужны **Node.js 24.9+** и npm. Репозиторий не содержит готовых аккаунтов или ключей.

```sh
git clone https://github.com/Domik-hub/konspekt.git
cd konspekt
npm ci
npm run local:build
npm run local:start
```

Открой **http://127.0.0.1:4317**. Сервер работает, пока запущена команда; остановка — Ctrl+C. После перезагрузки компьютера его нужно запустить снова. Новая сборка нужна после изменения интерфейса.

В Windows можно запускать в фоне командой `npm run local:open` и останавливать через `npm run local:stop`.

## Подключение ИИ

Для локальной версии API-ключ не требуется. Выбери сервис и заверши вход на его официальной странице. Чужая подписка не передаётся вместе с кодом.

| ИИ | Подключение |
| --- | --- |
| ChatGPT | Вход ChatGPT; доступные модели и лимиты определяются аккаунтом |
| Claude | Собственный аккаунт с доступом к Claude Code |
| Gemini | Вход Google и лимиты Gemini CLI |
| Grok | Аккаунт с доступом к Grok Build |
| Qwen | Qwen Code с подпиской Qwen Plus или Pro |
| DeepSeek | DeepSeek Harness; используется его баланс или бонусы |

Для всех сервисов, кроме встроенного подключения ChatGPT, сначала установи официальные клиенты:

```sh
npm run clients:install
```

Они устанавливаются только в локальную папку `.local-tools/`. Версии зафиксированы в `local/provider-packages.json`. Условия сервисов могут меняться. Вход и генерация через каждый сервис требуют отдельной проверки с подходящим аккаунтом.

## Данные и приватность

- `.local-data/` содержит личные подключения и не входит в Git. ChatGPT-токены на Windows защищены DPAPI; на других системах используются права доступа к файлам. Остальные клиенты сами хранят свои данные входа в отдельных профилях.
- Лекции разбираются в браузере. В режиме ИИ текст и ответы отправляются выбранному сервису.
- Наборы и результаты хранятся в localStorage выбранного браузера. Они не входят в репозиторий.
- Сервер слушает только `127.0.0.1`; эта конфигурация предназначена для работы на своём компьютере.
- `npm run privacy:check` проверяет отслеживаемые файлы и историю на случайное добавление локальных данных и известных форматов секретов. Это дополнительная проверка, а не гарантия обнаружения всех видов секретов.

## Разработка

```sh
npm run typecheck
npm test
npm run local:build
npm run privacy:check
```

GitHub Actions выполняет эти проверки на Windows и Linux. Тесты используют фикстуры: реальные аккаунты и платные запросы не нужны.

| Папка | Назначение |
| --- | --- |
| `app/` | Интерфейс, тренировки и маршруты размещаемой версии |
| `lib/` | Чтение файлов, контракты, генерация и проверка ответов |
| `local/` | Локальный сервер и подключения аккаунтов ИИ |
| `scripts/` | Проверки и инструменты разработки |

Подробности и ограничения: [техническая документация](README.konspekt.md). Для исходного варианта размещения на Sites см. [документацию среды](docs/sites-runtime.md). Личная конфигурация размещения `.openai/hosting.json` исключена из Git; её нужно настроить отдельно для своего проекта.

PDF-сканы без текстового слоя, OCR и аудиолекции пока не поддерживаются. Ответы нейросети стоит сверять с цитатами из лекции.
